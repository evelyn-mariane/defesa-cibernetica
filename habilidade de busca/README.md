# Habilidade de Busca (OSINT & Log Analysis) - TryHackMe

Esta pasta contém minhas anotações, registros visuais e resoluções práticas da sala focada em Habilidades de Busca no TryHackMe. O objetivo principal foi desenvolver técnicas de investigação, análise de pacotes e buscas avançadas para o contexto de defesa cibernética (Blue Team).

##  Objetivos e Aprendizados

* Análise de Tráfego: Utilização do Wireshark para filtrar e inspecionar pacotes de rede em busca de tráfego anômalo.
* OSINT no GitHub: Técnicas de busca avançada em repositórios públicos para localizar códigos, credenciais expostas ou ferramentas específicas.
* Documentação de Evidências: Extração manual de dados de logs e relatórios para estruturar uma linha do tempo de incidentes.

##  Ferramentas Praticadas

* Wireshark (Análise de arquivos .pcap)
* GitHub Advanced Search (Filtros de busca para investigação)
* Busca Manual de Logs
